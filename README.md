### 🔬 Architectural Focus & Technical Invariants

* **Deterministic Offline Execution**: Applications operate independently of central cloud infrastructure. Data serialization and processing execute locally on-device.
* **Low-Level Protocol Parsing**: Parsing raw bitstreams and network datagrams (ISO BMFF boxes, NAL units, UDP DNS packets) directly in memory without bloated abstraction layers.
* **Continuous Verification**: Repositories maintain automated CI test matrices across target environments (Python versions, node runtimes, modern Android SDKs).
* **Minimal Dependencies**: Preference for language standard libraries and platform-native primitives over heavy third-party framework dependencies.
